# JXL Studio Android v0.1.1

## 日本語

署名済みの jxl-studio-android.apk を端末へダウンロードして開いてください。Android 8.0以降のarm64 / x86_64端末に対応します。

ヘッダーの「日本語 / English」で言語を切り替えられ、選択は保存されます。JPEG・PNG等の一括可逆変換、JXL表示、ピンチ拡大、JXL / PNG保存に対応します。

変換結果は一時領域にあります。アプリ終了前に保存ボタンで端末に書き出してください。入力1ファイル128 MiB、一覧32件までです。

## English

Download and open the signed jxl-studio-android.apk on an Android 8.0+ ARM64 or x86_64 device.

Use the 日本語 / English buttons in the header to switch language. Your choice is saved. Includes lossless batch conversion, a JPEG XL viewer with pinch zoom, and JXL / PNG export.

Converted images are temporary: use Save before leaving the app. Inputs are limited to 128 MiB per file and 32 images per session.

Metadata is not retained; animations use the first frame. / メタデータ保持・アニメーション全体の変換は未対応です。
