# JXL Studio v0.1.1

## 日本語

日本語・英語の表示切り替えと設定保存を追加しました。画面右上の「日本語 / English」から選択できます。画像・変換一覧は維持されます。

Windows x64版ZIPを展開し、jxl-studio.exeを起動してください。READMEの先頭でも言語を切り替えられます。

## English

Added Japanese/English interface switching with a saved preference. Select 日本語 or English in the top bar; loaded images and the conversion queue are retained.

Extract the Windows x64 ZIP and launch jxl-studio.exe. Each README links to the other language.

Lossless conversion only. Metadata is not retained; animations use the first frame. / 可逆変換のみ。メタデータは保持せず、アニメーションは先頭画像のみを扱います。
